═══════════════════════════════════════════════════════════════════
   ⚙️ PARÁMETROS CONFIGURABLES
═══════════════════════════════════════════════════════════════════

TERRENO:
  • resolution: 20-500 (puntos por lado)
  • verticalScale: 0.5-5.0 (exageración altura)
  • realWorldSize: 100-5000 (metros)
  • vegetationDensity: 0-1 (0%-100%)

ANÁLISIS IMAGEN:
  • samplingRate: 2-50 (LOD - 1 de cada N píxeles)
  • Umbrales RGB para detección de features
  • minClusterSize: Tamaño mínimo de clusters

═══════════════════════════════════════════════════════════════════
   📊 RENDIMIENTO
═══════════════════════════════════════════════════════════════════

RECOMENDADO (Calidad/Velocidad):
  Resolution: 50×50 (2,500 puntos)
  LOD: 8 (analiza 12.5% de píxeles)
  Tiempo: ~50ms generación + ~100ms análisis
  FPS: 60 estable

ALTA CALIDAD:
  Resolution: 100×100 (10,000 puntos)
  LOD: 4 (analiza 25% de píxeles)
  Tiempo: ~200ms generación + ~300ms análisis
  FPS: 55-60

═══════════════════════════════════════════════════════════════════
   🧪 CÓMO PROBAR
═══════════════════════════════════════════════════════════════════

1. Abre:  open test-terrain-satellite-complete.html

2. (Opcional) Carga imagen satelital:
   - Screenshot de Google Maps modo satélite
   - Arrastra a la zona de carga
   - Presiona "Analizar Imagen"

3. Ajusta parámetros del terreno:
   - Resolución (50 recomendado)
   - Escala vertical (2.0)
   - Tamaño (1000m)
   - Vegetación (30%)

4. Presiona "GENERAR TERRENO 3D"

5. Explora con mouse:
   - Click + drag: Orbitar
   - Scroll: Zoom
   - Right click + drag: Pan

═══════════════════════════════════════════════════════════════════
   🔄 FLUJO DE DATOS
═══════════════════════════════════════════════════════════════════

1. BOUNDS (Leaflet) → Área del mapa
                ↓
2. POINT GRID → Grid uniforme lat/lon
                ↓
3. ENRICH DATA:
   ├─ HeightmapHandler → Elevación por punto
   ├─ VegetationHandler → NDVI por punto
   └─ SatelliteAnalyzer → Features visuales
                ↓
4. TERRAIN MESH (THREE.js):
   ├─ Vértices con altura
   ├─ Colores o textura satelital
   └─ Normales para iluminación
                ↓
5. VEGETATION LAYER:
   ├─ Filtrar por NDVI > umbral
   ├─ Determinar tipo (grass/bush/tree)
   └─ Colocar modelos 3D
                ↓
6. FEATURES (opcional):
   ├─ Renderizar caminos
   ├─ Colocar edificios 3D
   └─ Superficies de agua
